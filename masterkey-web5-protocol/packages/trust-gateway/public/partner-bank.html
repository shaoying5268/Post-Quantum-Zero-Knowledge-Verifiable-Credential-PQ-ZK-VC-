For Banks & Websites: Integrate in 2 Lines of Code

Any institution can paste this snippet onto their website to accept MasterKey users immediately:

<div id="masterkey-login-slot"></div>
<script src="https://masterkey.network"></script>
<script>
  MasterKeyConnect.renderButton('masterkey-login-slot', {
    institutionDid: 'did:web:your-bank-or-app.com',
    institutionName: 'Your Bank Name',
    onSuccess: (account) => console.log('Verified Customer:', account)
  });
</script>
